# DeepSeek API 2026 现状与 K12 英语应用调研

## 要点结论

1. **旧模型名已退役**:`deepseek-chat` 与 `deepseek-reasoner` 已于 2026-07-24 停止服务(2026-04-24 官方公告,三个月过渡期),退役前二者分别指向 V4-Flash 的非思考/思考模式——依据:DeepSeek 官方更新日志。
2. **当前可用模型为 V4 系列三款**:`deepseek-v4-flash`(当前指向 V4-Flash-0731,2026-07-31 发布)、`deepseek-v4-pro`(指向 V4-Pro-0813,2026-08-13 发布)、`deepseek-v4-flash-vision-exp`(2026-08-21 发布的实验性视觉模型)——依据:官方定价页与更新日志。
3. **上下文长度为 1M tokens**(全系),第三方资料称最大输出 384K tokens(此数字待核实)——依据:官方定价页 + DevTk 整理。
4. **定价为分时定价**:高峰时段为北京时间工作日 9:00–12:00 与 14:00–18:00,其余时段一律 5 折;最新费率 2026-08-16 生效,V4-Flash 峰时约 $0.44/M 输入(未命中)、$1.32/M 输出,V4-Pro 约为其 3 倍;缓存命中输入低至每百万 tokens 几美分级别(人民币精确数字待核实,以官方定价页实时为准)——依据:官方定价页 + 多家第三方价格整理。
5. **JSON 输出与 Function Calling 均支持**:两项能力自 2024-07-25 起提供并延续至 V4 全系(含思考/非思考模式切换);另有上下文硬盘缓存、File API,第三方称同时提供 OpenAI 与 Anthropic 兼容端点(后者待核实)——依据:官方文档功能页。
6. **DeepSeek 属已备案模型,但接入方仍有自己的合规义务**:中国实行"算法备案 + 大模型备案"双备案制;通过 API 调用已备案大模型对公众提供服务的应用,一般需做"大模型登记"(无需重复大模型备案),但若微调模型或自行面向公众提供生成服务则需备案;深度求索自身的备案号未在本次检索中直接核到原文,标注待核实——依据:观韬律所、阿里云开发者社区等合规解读。
7. **AIGC 标识为硬性要求**:《人工智能生成合成内容标识办法》自 2025-09-01 施行,生成内容须加显式/隐式标识——K12 产品输出的对话与题目均适用。
8. **未成年人合规单独成体系**:《未成年人网络保护条例》、《生成式人工智能服务安全基本要求》(要求设未成年人使用规则、防沉迷、监护人控制)、网信办《移动互联网未成年人模式建设指南》(2024-11)均适用;2025 年 12 月网信办进一步要求 AI 拟人化互动服务须具备未成年人身份识别并切换未成年人模式——K12 英语"情景对话"很可能被认定为拟人化互动服务。
9. **实践风险点已被媒体验证**:2026 年报道显示 AI 陪伴类产品"未成年人模式可绕过"是监管与舆情焦点,K12 产品需把身份识别与模式切换做实,不能只做前端开关。

## 关键细节

### 模型与定价(以官方定价页实时数据为准)

| 模型 | 版本 | 上下文 | 说明 |
|---|---|---|---|
| deepseek-v4-flash | V4-Flash-0731 | 1M | 轻量主力,支持思考/非思考模式,承接原 chat/reasoner 流量 |
| deepseek-v4-pro | V4-Pro-0813 | 1M | 高质量档 |
| deepseek-v4-flash-vision-exp | 2026-08-21 | 1M | 实验性视觉理解 |

- 第三方整理的美元价(每百万 tokens,2026-08-16 起,待核实):V4-Flash 错峰 缓存命中 $0.007 / 未命中 $0.22 / 输出 $0.66,峰时翻倍;V4-Pro 错峰 $0.022 / $0.66 / $1.98,峰时 $0.044 / $1.32 / $3.96。
- 官方页人民币口径:错峰输入缓存命中约 ¥0.05–0.15/M、输出约 ¥4.5–13.5/M(区间对应 Flash→Pro);另有报道称 Flash 缓存命中曾降至 ¥0.02/M,与上述有出入,精确值待核实。
- 缓存命中价与未命中价差约 30 倍,分时价差 2 倍——成本设计空间主要在这两处。

### 合规要点(中国大陆面向公众的 K12 产品)

- 双备案制:自研/微调并对公众提供生成服务 → 算法备案 + 大模型备案;仅 API 调用已备案模型 → 大模型登记 + 深度合成/算法备案(按属地网信办口径执行,流程口径各地有差异,待核实)。
- 内容安全:《生成式人工智能服务安全基本要求》要求关键词库 + 分类模型 + 人工监看三层机制,监看人力与服务规模匹配;对用户输入与模型输出双向监管。
- 未成年人:适龄内容评估、防沉迷/使用时长、监护人管理、身份识别与未成年人模式(2025-12 新规对拟人化互动明确提出)、申诉渠道。
- 标识:显式标识(界面提示"AI 生成")+ 隐式标识(元数据),2025-09-01 起强制。
- 数据:学生成绩、学习行为属敏感个人信息,收集最小化 + 未成年人个保需监护人同意(《个人信息保护法》14 岁以下)。

### K12 英语情景对话/出题的实践注意点

- 系统提示词护栏:锁定角色(英语老师/对话伙伴)、锁定话题白名单(校园、家庭、购物等课标场景)、明确拒答范围(暴力、色情、自伤、政治敏感、诱导线下接触、索取个人信息),并要求"始终以适龄语言回复"。
- 把长而稳定的护栏系统提示 + few-shot 示例放在提示前缀,吃缓存命中价,成本几乎可忽略。
- 防提示词注入/越狱:学生输入只作为 user 消息注入,不拼接进 system;对"忽略以上指令"类模式做前置过滤;输出后再过一层审核(自建关键词 + 第三方内容安全 API,如数美/易盾类)。
- 出题用 JSON 输出模式或 Function Calling 强约束 schema(题干、选项、答案、解析、CEFR/年级难度标签),并在服务端做 schema 校验 + 重试;题库类离线生成安排在错峰时段跑批,费用减半。
- 对话用非思考模式保低延迟;出题、判分、纠错讲解可用思考模式或 v4-pro 保质量。
- 留存对话日志用于监看抽查与申诉举证(注意未成年人数据的存储期限与加密)。

## 接入架构建议要点

1. 服务端代理统一持有 API Key,客户端绝不直连 DeepSeek;代理层做限流、计费归集、模型路由(对话→v4-flash 非思考;出题/批改→v4-flash 思考或 v4-pro)。
2. 三明治安全层:输入预过滤(关键词/分类器/注入检测)→ 模型(护栏 system prompt 固定前缀)→ 输出后过滤(内容安全 API + schema 校验),任一层拦截即走兜底话术。
3. 成本设计:稳定前缀吃缓存;题库离线错峰批量生成;对话按轮次截断历史控制未命中输入量。
4. 合规模块内置:未成年人身份识别与未成年人模式、监护人面板、使用时长控制、AI 生成显式/隐式标识、举报申诉入口、日志留存;上线前完成算法备案/大模型登记评估。
5. 可用性:官方模型名会随版本漂移(chat/reasoner 已退役先例),模型 ID 收敛为配置项并订阅官方更新日志;准备降级/备用模型通道。
