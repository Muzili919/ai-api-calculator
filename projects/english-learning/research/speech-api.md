# 中国市场英语口语评测(发音评分)API 调研汇报

## 要点结论

1. **五家中真正可"自助开通、公开文档"的是讯飞、腾讯云、有道三家**——讯飞开放平台语音评测(ISE)、腾讯云智聆口语评测(SOE)、有道智云语音评测均有公开 API 文档和控制台自助接入;驰声(Chivox)以商务洽谈为主,百度智能云未见独立公开的口语发音评测 API 产品(其语音产品线以识别/合成为主,「待核实」是否有行业定制方案)。
2. **音素级反馈三家均具备**:腾讯云 SOE 明确宣称"精准到音素级发音对比",支持音素/拼音级注音参数;有道宣称"单词、句子、段落音素级全面遍历"并做错误定位;讯飞英文评测按官方文档可返回多维度得分与发音错误定位(音素/音节级细节字段以 IseAPI 文档为准,「待核实」具体粒度)。
3. **评测题型覆盖最广的是腾讯云 SOE 与驰声**:SOE 支持字/词/句/段落/自由说/多分支/关键词等模式;驰声宣称覆盖 260+ 种中英文评测题型并解决了复杂题型(语法、内容)的 AI 评分。讯飞支持词/句/篇章及"全维度评测",自由说能力未在公开页面明确(「待核实」)。
4. **中高考对标能力最强的是驰声**:官网宣称服务中高考英语听说考试 11 年,受邀参与北京、上海、广东、广西、湖北、宁夏、辽宁等省市的考试方案设计、技术验证与落地;讯飞同为多省市听说考试技术方深度参与者(其 AI 研究院有公开论文论述语音评测用于英语听说教学与评价,具体承接省份「待核实」)。腾讯云、有道未见明确的中高考承考背书。
5. **价格公开透明度普遍不高**:讯飞可免费领取 5 万次服务量(SDK 与 WebAPI 分开领取、量不互通),篇章阅读/全维度评测等高级功能可在控制台申请试用;腾讯云 SOE 为预付费资源包+后付费按量两种形式、中英文合并计费(具体单价「待核实」,需看购买页);有道新用户赠 50 元体验金;驰声不公开报价。**所有按次单价均建议以控制台实时报价为准,本报告不列未经核实的数字。**
6. **接入方式**:讯飞为 WebSocket 流式 WebAPI + 各端 SDK;腾讯云为 REST API(流式/非流式两种工作模式,初始化+传输分阶段)+ SDK;有道为 REST API(一句话/实时评测,要求 16k/16bit PCM)+ iOS/Android SDK;驰声以 SDK/私有化集成为主,已进入 App、词典笔、学习平板、VR 眼镜等形态。
7. **选型倾向**:做**中高考模拟/教考练产品**优先驰声(考试同源引擎)、次选讯飞;做**通用 App 跟读打分**且已用腾讯云生态选 SOE(模式丰富、按量计费灵活);**轻量接入、预算敏感**选讯飞(免费额度大)或有道;百度智能云不建议作为口语评测首选。
8. **驰声与"声通"的关系需注意**:Chivox 即苏州驰声;用户提到的"声通"若指上海声通(Syntheto/声通科技)则是另一家公司,本次检索未获其口语评测 API 公开资料(「待核实」)。

## 关键细节

### 科大讯飞 语音评测(ISE,流式版)
- 支持中文普通话与英文;题型含字/词/句/篇章;返回准确度、流畅度、完整度、声韵调等多维度得分,并做发音错误、缺陷定位与问题分析;按年龄段提供不同打分标准。
- 已全面升级为流式版,官方称"篇章阅读、全维度评测等功能免费开放";高级功能走控制台"语音评测-高级功能-试用申请"。
- 免费额度:每用户可分别领取 SDK 版与 WebAPI 版各 5 万次服务量,两者不互通;大批量采购可申请商务折扣(阈值表述「待核实」)。
- 接入:wss 流式 WebAPI(文档中心 `doc/Ise/IseAPI.html`)、Android/iOS/Windows/Linux SDK。

### 腾讯云 智聆口语评测(SOE)
- 全年龄段覆盖;模式:字、词、句、段落、自由说、多分支、关键词;返回准确度、流畅度、完整度、重音、声调、音素等细粒度结果;支持检测漏读、多读、错读、重复朗读;支持音素与拼音级注音参数配置。
- 计费:英文版与中文版合并计费、资源共享;预付费资源包与后付费按量两种(单价「待核实」,见腾讯云购买页 buy.cloud.tencent.com/pricing)。
- 存在"基础版"(product/884)与"新版"(product/1774)两条产品线,新项目建议评估新版接口。
- 接入:REST API(TransmitOralProcessWithInit 等,初始化+评估两阶段,流式 isEnd 分片或整包上传)、各语言 SDK。

### 有道智云 语音评测
- 中英文朗读评测(CAPT):准确度、完整度、流利度、声韵调多维评分;错误定位、纠错与分析;单词/句子/段落音素级全面遍历。
- 实时语音评测 API:音频要求 16K 采样、16bit PCM(pcm_s16le)。
- 新用户注册赠 50 元体验金;各接口有一定免费量(具体量「待核实」)。
- 接入:REST API + iOS/Android SDK;网易有道教育场景(词典、翻译)同源技术。

### 百度智能云
- 语音产品线公开目录为短语音识别、实时识别、语音合成、自训练平台等;本次检索**未找到独立公开的英语口语发音评测 API 产品页**。第三方对比文章提及其短语音识别入门套餐约"1 万次/50 元、每月有赠送量"(为识别而非评测,且数字「待核实」)。
- 结论:如必须用百度系,需走行业方案商务洽谈,不建议作口语评测首选。

### 驰声 Chivox
- 2007 年起自研语音识别与评测引擎;服务中高考英语听说考试 11 年,参与北京、上海、广东、广西、湖北、宁夏、辽宁等省市考试的方案设计、技术验证与落地。
- 宣称口语评测准确率 98%+、系统稳定性 99.9%(厂商自述,「待核实」);覆盖 260+ 中英文评测题型;支持复杂口语题型(语法、内容)AI 评分。
- 提供校园听说教考练平台(模拟考试系统);API 已集成于 App、教育平板、词典笔、VR 眼镜等。
- 价格与并发均为商务报价,不公开。
