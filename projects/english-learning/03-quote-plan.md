# 03 · 报价与交付测算(内部)

> 甲方盘面:**8 个班 · 平板部署 · 预算 10 万**。
> 假设:45 人/班 ≈ **360 名学生**;平板为学校已有/另行采购(10 万为软件与服务预算)。
> ⚠️ 若「8 个班」指每个年级 8 个班(24 班 ≈ 1080 人),API 成本约 ×3,仍在毛利安全区,但服务与培训工作量要重估——签约前必须确认这一条。

## 1. 这 10 万在市场上是什么水位

- 折算 **¥278/生/年**(10 万 ÷ 360)——正好落在 E听说约 200-365 元/生/年的市场锚点区间内
- 但形态完全不同:E听说是家长自愿付费的标准品;我们是**学校统一采购、学生零付费、定制交付**——价格相同,合规性和体验都占优,这个对比讲给校长听

## 2. 年度硬成本测算(360 人,数字为估算,签约前按官方实价复核)

| 项 | 用量假设 | 年成本估算 |
|---|---|---|
| DeepSeek(对话/批改/出题) | 15 轮/生/日 × 180 天,护栏前缀缓存命中 ~70%,题库错峰批量 | **< ¥3,000**(v4-flash 为主,惊人地便宜) |
| 语音评测 | ~12 次/生/日 × 180 天 ≈ 78 万次/年 | ¥5,000–10,000(商务价谈判,含并发包)|
| TTS 音频 | 单词/课文音频生成一次全校复用(缓存) | 忽略不计 |
| 云服务器 + CDN + 存储 | 单实例 + 对象存储 + 备案 | ¥3,000–5,000 |
| 内容安全审核 API | 对话双向审核 | ¥1,000–2,000 |
| **合计** | | **≈ ¥1.2 万–2 万/年** |

→ 硬成本约占预算 15-20%,**毛利空间约 8 万**,一人公司 + AI 杠杆做一学年,健康。

**并发设计(平板场景特有)**:8 班同时上课理论峰值 360 路,但课表错峰实际按 **4 班 ≈ 180 路**设计;语音评测并发包按 ≥100 路谈,课堂模式做请求队列削峰。这一条写进技术方案,别到开学第一课翻车。

## 3. 报价结构建议(关键:别卖成永久买断)

| 结构 | 金额 | 内容 |
|---|---|---|
| **首年合同** | **¥100,000** | 平台开发交付 + 首学年内容与运营服务(见 §4 范围)|
| 续费年费 | ¥30,000–35,000/年 | 内容年更(含考纲更新)+ API 成本 + 运营服务 + 功能迭代 |
| 付款节奏 | 40% 签约 / 30% MVP 上线验收 / 30% 学期末验收 | 与手册付款条款一致 |

话术:「首年含一次性的平台建设,续费只收服务与内容更新」——续费 3 万出头对学校是小钱,对我们是**年年滚的被动现金流 + 案例复利**。绝对不签"10 万永久买断含终身服务",那是给自己挖坟。

## 4. 10 万范围清单(逐条写进合同附件)

### ✅ 范围内(首年)

1. **学生端**(平板 PWA,横竖屏适配):单词/拼写/跟读/情景对话(AI 真对话)/单元小测 + 神兽/锦囊/吧唧墙/班级团战(基础版)
2. **中考听说模考**:5 大题全真流程 + 朗读 24 篇 + 话题 12 个 + 情景问答 + 听力两题型,五维评分
3. **内容滚动交付**:覆盖**当学期各年级在教单元**,领先教学进度 ≥2 周(不是一次性交付三个年级全部历史单元——这是范围控制的命门)
4. **教师端**(Web 基础版):布置作业、班级学情、组织模考、成绩导出
5. **家长通知**(轻量):微信 H5 周报链接,不做独立家长 App
6. 部署上线 + 教师培训 2 场 + 每学期数据报告 1 份 + 工作日 48h 响应
7. 视觉:现有「书山」风格系统 + 委托 1 套神兽 IP 立绘(预算内)

### ❌ 范围外(列明,二期报价)

- 配音剧场(AIGC 短片制作费另计;**可送 1 部作首年彩蛋**,埋二期钩子)
- 三个年级全部历史单元回溯、作文批改教师复核工作流(首年 AI 批改先行)
- 私有化部署(首年云部署;学校要求私有化则另议)
- 独立家长 App、校级数据大屏

## 5. 平板部署技术要点

- **录音权限**:getUserMedia 需 HTTPS;安卓平板 WebView/浏览器差异大,签约后第一周先拿校方平板做**机型适配清单**(录音、TTS、PWA 安装三项过检)
- **管控配合**:接入学校现有平板管控(希沃/鸿合类)的白名单即可,我们不重复做 MDM;若平板无管控,提供浏览器 Kiosk 方案建议
- **弱网设计**:课文与单词音频预下载;录音先本地缓存再上传重试;断线不丢答题进度
- **课堂模式**:教师端一键发起全班同步练习(答题进度实时上墙),这是平板课堂的核心使用形态,MVP 必含

## 6. 里程碑(按学期节奏)

| 周 | 交付 |
|---|---|
| W1-2 | 合同细化 + 机型适配清单 + API 商务谈判(语音评测并发包)|
| W3-8 | MVP:学生端核心闭环 + 模考模块 + 教师端基础版(付款节点 2)|
| W9-10 | 试点 2 个班上线 · 学生投票定皮肤(A/B)|
| W11 起 | 全 8 班铺开,内容滚动交付,双周迭代 |
| 学期末 | 数据报告 + 评分对齐分析(付款节点 3)→ 谈续费与二期 |

## 7. 风险与对策

- **「8 个班」口径**:总共 8 班 vs 每年级 8 班,签约前书面确认(影响 API 成本与培训量)
- **预算性质**:确认 10 万是纯软件服务,不含平板采购;含税与否、对公开票税点算清再报
- **范围蔓延**:所有「顺便加个功能」走双周迭代池,超出附件清单的按二期报价——合同里写明
- **API 单价**:本文档所有 API 数字为估算,商务谈判后把实价回填此表;若语音评测报价超预期,备选方案为腾讯 SOE 按量计费
