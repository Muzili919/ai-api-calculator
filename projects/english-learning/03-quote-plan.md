# 03 · 报价与交付测算(内部)

> 甲方盘面(2026-08 确认):**每年级 7 个班 × 3 个年级 = 21 个班,约 65 人/班 ≈ 1,365 名学生 · 平板部署 · 预算 10 万**。
> 假设:平板为学校已有/另行采购,10 万为软件与服务预算。

## 1. 这 10 万在市场上是什么水位

- 折算 **¥73/生/年**(10 万 ÷ 1,365)——**远低于** E听说约 200-365 元/生/年的市场锚点
- 对学校:同样的能力,**每个学生一年 73 块**,还不用家长掏一分钱。这个数字直接讲给校长听,杀伤力极大
- 对我们:单价低意味着**必须靠规模和续费赚钱,不能靠首年**——所以续费必须按人头定价(见 §3)

## 2. 年度硬成本测算(1,365 人,数字为估算,签约前按官方实价复核)

| 项 | 用量假设 | 年成本估算 |
|---|---|---|
| 语音评测 | 1,200–2,160 次/生/年 → **164 万–295 万次/年** | **¥8,000–30,000**(全部变数在这里,见下)|
| DeepSeek 对话 | 10 轮/生/周 × 40 周 ≈ 55 万轮,峰时口径 | ¥600–1,500 |
| DeepSeek 批改/出题 | 作文批改 + 题库讲解(错峰批量) | ¥2,000–4,500 |
| 云服务器 + 数据库 | 峰值 260 路并发,需正经实例 + Redis + PG | ¥6,000–10,000 |
| 示范音 TTS | **批量预生成一次**(约 17 万字符),CDN 复用 | **一次性 ≈ ¥27**,年度 ≈ 0 |
| 音频 CDN 流量 | 学生端预下载,重复播放不回源 | ¥1,000–2,000 |
| 内容安全审核 | 对话双向审核约 110 万次 | ¥2,000–4,000 |
| **合计** | | **≈ ¥2 万–5.2 万/年** |

→ 毛利 **¥4.8 万–7.2 万**。能做,但比 360 人的假设紧得多,**且全部风险集中在语音评测报价上**。

### ⚠️ 语音评测:1,365 人规模下必须换采购方式

按次计费在这个量级会失控(295 万次/年)。三条对策,按优先级:

1. **谈包年/并发授权**,不按次计费——1,365 人、平板部署正是驰声「已集成于教育平板」的典型场景,这类规模谈包年通常显著便宜
2. **控制评测触发点**:不是每句都评。跟读只评整段、模考按题评、日常练习抽评——同样的学习效果,调用量可降 40%+
3. 讯飞 ISE 免费额度(SDK/WebAPI 各 5 万次)只够 MVP 与试点,**不要拿它当全量方案的成本基础**

W1-2 的商务谈判把这条谈定,再签合同。

### 实测记录 · 讯飞语音评测(2026-08,已跑通)

- 应用已建,APPID `885381d1`;**语音评测在控制台「语音扩展」下**,不在一级菜单
- 免费额度 10,500 次,到期 2026-11-25;IP 白名单默认关闭(不用改)
- ⚠️ **英文评测(`ent: en_vip`)不能传 `group` 参数**(那是中文评测专用),传了必报 `48195 iSEInputAppend error`——排查了半天的坑,已写死在 `server/xf.mjs`
- 文本必须是 `\uFEFF[content]\n` + 待评测文本(BOM 不能省)
- 讯飞在线 TTS 英文音色:`x4_EnUs_*` 系列未开通,**`catherine` 可用**(美音;英式示范音仍建议走 Azure,见 04)
- **评分实测**:同一段音频
  · 文本匹配 → 总分 4.93/5(准确 4.89 / 流利 5.00 / 完整 5.00 / 标准 5.00),逐词逐音素均有分
  · 文本不匹配(模拟念错)→ 总分 0.03/5,完整度 0.63,错词全 0
  → 引擎确实在区分对错,不是摆设

### 实测记录 · DeepSeek(2026-08,demo 服务端已跑通)

- 可用模型:`deepseek-v4-flash` / `v4-pro` / `v4-flash-vision-exp`(与调研一致)
- ⚠️ v4-flash **默认思考模式**,对话必须传 `"thinking": {"type": "disabled"}`,否则 token 全烧在推理上且延迟高;`enable_thinking`/`reasoning` 等写法会被静默忽略
- ⚠️ **上课时段(9-12 / 14-18)正好是 DeepSeek 高峰计费时段**,题库/讲解等离线任务一律排到错峰跑(5 折)
- JSON 输出稳定;护栏前缀缓存生效(第二轮起 cache_hit);语法纠错质量佳;注入语句被前置过滤拦截

### 并发设计(65 人大班特有)

- 课表错峰按 **4 班同时上课 × 65 人 ≈ 260 路**设计(不是全校 1,365)
- **课堂模式是瞬时峰值**:老师喊"开始跟读",65 人同时点 → 一秒内 65 路评测请求。必须做**请求队列 + 客户端随机抖动(0-2s)**,否则第一节公开课就翻车
- 语音评测并发包按 ≥150 路谈

## 3. 报价结构建议(关键:别卖成永久买断)

| 结构 | 金额 | 内容 |
|---|---|---|
| **首年合同** | **¥100,000** | 平台开发交付 + 首学年内容与运营服务(见 §4 范围)|
| 续费年费 | **¥35/生/年**(1,365 人 ≈ ¥48,000/年) | 内容年更(含考纲更新)+ API 成本 + 运营服务 + 功能迭代。**必须按人头定价**:学校扩班/扩年级我们才不亏 |
| 付款节奏 | 40% 签约 / 30% MVP 上线验收 / 30% 学期末验收 | 与手册付款条款一致 |

话术:「首年含一次性的平台建设,续费只按在用学生数收服务费」——¥35/生/年对学校仍是同类产品的零头,对我们是**年年滚的被动现金流 + 案例复利**。绝对不签"10 万永久买断含终身服务",那是给自己挖坟。

### 首年范围的两个选项(建议与甲方明确二选一)

| | A:全校 21 班铺开 | **B:首年 1-2 个年级(推荐)** |
|---|---|---|
| 覆盖 | 1,365 人,¥73/生/年 | 七年级 7 班 455 人,¥220/生/年 |
| 内容工作量 | 3 个年级同时滚动交付 | **1 个年级,工作量 1/3** |
| 硬成本 | ¥2 万–5.2 万 | ¥1 万–2 万 |
| 风险 | 单价低、内容压力大、评测成本敏感 | 可控;跑顺再扩,扩班即加费 |
| 续费逻辑 | 靠维持 | **七年级学生跟平台走三年,续费天然** |

推荐 B,并把 A 作为"第二年扩面"的目标写进方案——先把一个年级做到school里人人称赞,比三个年级都做得平庸强。若甲方坚持 A,则必须先谈定评测包年价,并把首年内容明确限定为"当学期在教单元"。

## 4. 10 万范围清单(逐条写进合同附件)

### ✅ 范围内(首年)

1. **学生端**(平板 PWA,横竖屏适配):单词/拼写/跟读/情景对话(AI 真对话)/单元小测 + 神兽/锦囊/吧唧墙/班级团战(基础版)
2. **中考听说模考**:5 大题全真流程 + 朗读 24 篇 + 话题 12 个 + 情景问答 + 听力两题型,五维评分
3. **内容滚动交付**:覆盖**当学期各年级在教单元**,领先教学进度 ≥2 周(不是一次性交付三个年级全部历史单元——这是范围控制的命门)
4. **教师端**(Web 基础版):布置作业、班级学情、组织模考、成绩导出
5. **家长通知**(轻量):微信 H5 周报链接,不做独立家长 App
6. 部署上线 + 教师培训 2 场 + 每学期数据报告 1 份 + 工作日 48h 响应
7. 视觉:现有「书山」风格系统 + 委托 1 套神兽 IP 立绘(预算内)

### ❌ 范围外(列明,二期报价)

- 配音剧场(AIGC 短片制作费另计;**可送 1 部作首年彩蛋**,埋二期钩子)
- 三个年级全部历史单元回溯、作文批改教师复核工作流(首年 AI 批改先行)
- 私有化部署(首年云部署;学校要求私有化则另议)
- 独立家长 App、校级数据大屏

## 5. 平板部署技术要点

- **录音权限**:getUserMedia 需 HTTPS;安卓平板 WebView/浏览器差异大,签约后第一周先拿校方平板做**机型适配清单**(录音、音频播放、PWA 安装三项过检)
- **⚠️ 不用浏览器 TTS**:安卓平板常缺 en-GB 音色,会退化成美音或机械音、甚至不发声。示范音一律用预生成 MP3(见 [`04-speech-decision.md`](04-speech-decision.md))
- **管控配合**:接入学校现有平板管控(希沃/鸿合类)的白名单即可,我们不重复做 MDM;若平板无管控,提供浏览器 Kiosk 方案建议
- **弱网设计**:课文与单词音频预下载;录音先本地缓存再上传重试;断线不丢答题进度
- **课堂模式**:教师端一键发起全班同步练习(答题进度实时上墙),这是平板课堂的核心使用形态,MVP 必含

- ~~「8 个班」口径~~ **已确认**:每年级 7 班 × 3 年级 = 21 班,65 人/班 ≈ 1,365 人
