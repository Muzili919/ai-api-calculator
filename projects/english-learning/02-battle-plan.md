# 02 · 对标方案:定制平台 vs 市面头部产品(科大讯飞)

> 基于 8 组并行调研(原始资料见 [`research/`](research/) 目录,含全部来源链接)。
> 甲方场景:学校在与讯飞接触,我们的定位是「讯飞能做的功能全覆盖 + 定制化做得更贴合」。
> ⚠️ 本文档含竞争策略,**强烈建议将本仓库转为私有**或将本目录移至私有仓库。

## 0. 一句话战略

**不在引擎上比精度,在贴合上比体验。**
江苏中考听说考试由省统一组织(2009 年起,省教育厅联合中科院自动化所等开发),市面所有备考产品——包括 E听说——在江苏都是「仿真模拟」,评分可信度都要靠与真实考试对齐来证明。我们与讯飞在同一起跑线,而定制、内容贴校、AI 对话自由度、价格结构是我们的主场。

## 1. 功能对标矩阵(讯飞能做的,我们怎么做)

讯飞产品矩阵 = AI学习机(家庭)+ 英语通(硬件)+ E听说中学/智学网(校内)+ 翻译笔。逐项对标:

| 讯飞功能 | 所在产品 | 我们的实现 | 对标结论 |
|---|---|---|---|
| 中高考听说全真模考 | E听说中学 | **江苏中考 5 大题全流程仿真**(见 §2),年更考纲 | ✅ 平价,且只做江苏做得更深 |
| AI 口语陪练 / AI 外教对话 | 学习机、英语通 | DeepSeek 驱动的自由情景对话 + 语音评测逐句反馈 | ✅ 且自由度更高(讯飞被评测指「跟读打分为主,针对性纠错有限」) |
| 口语发音评测(逐句打分) | 全线 | 讯飞开放平台 ISE / 驰声引擎(商用采购,见 §4) | ✅ 同源技术采购,精度不吃亏 |
| AI 作文批改(逐词逐句) | 学习机、E听说 | DeepSeek(思考模式)批改 + 教师复核工作流 | ✅ 平价 |
| 教材同步听力/课文跟读 | 英语通、E听说、翻译笔 | 译林版单元同步(版权路线见 §6) | ✅ 平价 |
| AI 精准学(学情诊断→路径) | 学习机 | FSRS 间隔重复 + 错因归类 + 单元知识点图 | ✅ 轻量版,初中英语够用 |
| 单词/音标/听力专项 | 英语通、E听说 | 词汇(SRS+拼写)、音标闯关、听力两大题型专项 | ✅ 平价 |
| 教师端布置作业/模考、班级学情 | E听说校端、智学网 | **教师端是标配**(见 §7),轻量不折腾 | ✅ 必须做,这是成交关键 |
| 全科答疑、互动课、翻译笔硬件 | 学习机、翻译笔 | ❌ 不做 | 明确不对标:我们只做英语听说读写,不卖硬件 |

**给甲方的口径**:讯飞英语相关的核心功能(模考/陪练/评测/批改/同步练)全部覆盖;我们不做的是它的全科硬件生态——学校买英语听说能力,不需要为一台学习机的全科功能付费。

## 2. 杀手锏:江苏中考听说模考(考什么练什么)

现行考纲(2025 改革后、2026 口径,来源见 research/jiangsu-exam.md):

- 满分 **30 分**,约 30 分钟,全省统一机考(4 月最后一个周末,2026 年为 4/25-26)
- 听力:听对话回答问题 10 分 + 听对话和短文答题 10 分
- 口语:**朗读短文 3 分**(2026 年官方 24 篇,全部出自译林版教材)+ **情景问答 2 分** + **话题简述 5 分**(官方 12 话题、无中文提示、无范文、至少连说 7 句)

我们的模考模块(全部进 MVP):

1. 全真模考:5 大题完整流程,试音→计时→交卷,界面节奏仿机房
2. 朗读 24 篇专练:逐句跟读 + 整篇限时,错读单词逐个标红
3. 话题简述 12 题专练:自建简述稿→背诵检测→脱稿录音,AI 判「是否 ≥7 句 + 内容/语法/流利度」
4. 情景问答即时应答题库 + 听力两大题型错因归类(数字/时间/地点…)
5. 五维评分报告(语音准确性/流利度/内容完整性/语法/韵律,对齐省考维度)
6. **年更承诺写进合同**:每年考纲发布后 30 天内完成篇目与话题更新(2026 年即新增 6 篇朗读)

**评分可信度验证方案**(甲方必问,提前备好):试点学期采集学生校内模拟考成绩与平台评分做相关性分析(需家长知情同意),用数据证明「平台分≈考试分」;这一步讯飞在江苏同样要做,谁先在**这所学校**做完,谁的分数就更可信。

## 3. 差异化八张牌(讯飞真实痛点 → 我们的做法)

来源:黑猫投诉/知乎/媒体评测(research/iflytek-pain.md),对外表述只陈述我们的承诺,不贬损对手:

| # | 讯飞侧公开痛点 | 我们的牌 |
|---|---|---|
| 1 | 万元硬件 + 会员/增强包多层收费争议 | **学校采购制一口价,学生家长零付费**(也是进校合规要求) |
| 2 | 内容时效性差、同步课单一 | 内容跟着**这所学校**的进度与考纲走,年更写进合同 |
| 3 | 非每题有讲解、AI 误判卡死 | 每题 AI 讲解(DeepSeek 生成+抽样人审),判错可一键报错、48h 修复 |
| 4 | 口语「跟读打分为主,纠错有限」 | 自由对话 + 逐句纠错 + 换说法建议,不止打分 |
| 5 | 硬件过保维修贵、售后差 | 纯 Web 零硬件,学校现有机房/平板直接用 |
| 6 | 型号迭代快、老用户被背刺 | Web 端永远是最新版 |
| 7 | 家长管控不完善 | 家长/教师双端管控是一等公民(时段、时长、内容) |
| 8 | 大公司流程慢、小校订单优先级低 | 创始团队直接服务,需求两周一迭代,校长微信直达 |

## 4. 技术架构(甲方给的两个 API 用在哪)

```
学生端(Web,机房 PC / 平板 / 家庭浏览器)
   │
后端代理(统一持有 Key,客户端绝不直连)
   ├─ 对话路由:deepseek-v4-flash 非思考模式(低延迟情景对话)
   ├─ 质量路由:v4-flash 思考模式 / v4-pro(出题、作文批改、讲解生成)
   ├─ 语音评测:讯飞 ISE(起步,免费 5 万次/端)或驰声(考试级,商务)
   │            备选:腾讯 SOE(题型最全,音素级)
   └─ 三明治安全层:输入预过滤 → 护栏 system prompt(固定前缀吃缓存)
                    → 输出过滤(内容安全 API + schema 校验)
```

要点(全部来自 research/deepseek-api.md、speech-api.md):

- **模型现状**:deepseek-chat/reasoner 已于 2026-07 退役;现用 `deepseek-v4-flash`(0731)/`deepseek-v4-pro`(0813),1M 上下文,支持 JSON 输出与 Function Calling。模型 ID 做成配置项,防版本漂移
- **成本设计**:护栏提示词固定前缀吃缓存命中价(与未命中差约 30 倍);题库/讲解离线错峰批量生成(分时 5 折);对话历史按轮截断
- **单位经济粗算**(假设生均 20 轮对话/天 × 200 天,单价以官方页实时为准):LLM 约几元/生/年;语音评测 4000 次/生/年,按公开单价区间约 20-80 元/生/年,商务采购可压;**技术成本合计约 30-90 元/生/年,对照 E听说约 200-365 元/生/年的市场锚点,定价空间健康**(以上均需按控制台实价复核,已标注于调研文件)
- 语音评测选型:MVP 用讯飞 ISE(额度大、接入快)→ 规模化后与驰声谈考试级引擎(服务多省中高考 11 年)。**引擎是采购件,不是我们与讯飞的胜负手**

## 5. 视觉方向(初中生审美调研结论)

核心发现(research/teen-aesthetic.md):**蛋仔式圆萌卡通 = 「小学生」标签**,初中生的「酷」在:战术/电竞、酷帅二次元、新中式国潮、谷子(吧唧徽章)收集文化(2025 年谷子市场超 2400 亿,吧唧占闲鱼谷子销量 64%,单价 10-20 元正好是初中生零花钱)。

三个候选方向(都通过「学生觉得酷 + 校长能接受」双重筛选):

| 方向 | 参照物 | 关键元素 | 风险 |
|---|---|---|---|
| A 新中式 × 二次元 | 原神璃月、国创番剧海报、故宫文创 | 水墨+扁平插画、黛青/朱砂/月白+金、竖排书法混排、酷帅立绘 | 美术成本最高 |
| B 电竞 / 科幻 HUD | 无畏契约、三角洲、KPL 赛事视觉 | 深空底+单一霓虹色、斜切几何、准星/数据条 HUD 符号、等宽字 | 需去武器化;女生接受度待验证 |
| C 谷子徽章收集 | 吧唧墙、集换卡稀有度、成就徽章 | 徽章为核心图形单元、R/SR/SSR 分级烫金、成套收集+隐藏款 | 单独用略单薄,适合做机制层 |

**推荐:C 为机制层(把现有宠物/盲盒循环升级为「徽章+卡牌收集」体系,R/SR/SSR 稀有度),皮肤在 A/B 中选**——并且不要我们拍板:**试点班 50 名学生投票选 A 或 B**,把选择权做成甲方汇报里的亮点(「你们的学生自己选的界面」,校长非常吃这套参与感)。

游戏化机制同步吸收多邻国系打法(research/edu-app-design.md):连胜+里程碑庆祝、可变奖励宝箱、双货币、拟人化 IP 陪学、动效当核心资产(Rive/Lottie)。
⚠️ **合规改造**:教育部禁止公布学生成绩排名 → 多邻国式真实排行榜进校违规,改为**匿名段位制**(青铜→王者,只见段位不见姓名成绩)+ 自我进步曲线。

## 6. 合规红线(进校产品,一条都不能碰)

1. **教育 App 备案 + 省级进校白名单**(教育部 2019 意见):Web 平台若以 App/小程序形态进校需完成备案;纯 Web 校内部署口径向属地教育局确认
2. **不得植入广告、不得向学生强制收费** → 学校采购制,产品内零商业化
3. **禁止公布成绩排名** → 匿名段位 + 个人进步维度(见 §5)
4. **教材版权**:译林牛津教材课文/配套音频归出版社;路线 = 单词表+原创例句短文自建(现行做法)/ 甲方以学校名义与出版社谈授权;**朗读 24 篇、12 话题清单为考试院公开发布,引用清单本身风险低,篇目原文仿真需注意**
5. **生成式 AI**:DeepSeek 为已备案模型,我们作为接入方做大模型登记评估;AI 生成内容加显式+隐式标识(2025-09 起强制);**AI 拟人化对话须内置未成年人模式与身份识别**(2025-12 新规,不能只做前端开关)
6. **未成年人数据**:学习行为属敏感信息,最小化收集、14 岁以下监护人同意、数据归属学校写进合同

## 7. 教师端(成交的真正关键,批判 agent 指出的盲区)

采购决策人是校长/教研组,E听说的校内粘性正来自师生联动。MVP 必含:

- 布置作业(按单元/题型/篇目勾选,一键下发到班)
- 班级学情看板(完成率、平均分、薄弱题型分布、需关注学生)
- 组织模考(全班同步模考 + 成绩导出 Excel/PDF,报教务)
- 学期报告(自动生成,给校长看的那种)

## 8. 里程碑(修订)

| 阶段 | 内容 |
|---|---|
| M1 方案确认 | 本方案 + 汇报页过会;确认版权路线、视觉方向投票机制 |
| M2 MVP(6-8 周) | 七年级 2 单元全闭环 + 中考模考(朗读/话题/情景问答)+ 教师端基础版 + 匿名段位 |
| M3 试点学期 | 2 个班跑一学期;评分对齐验证;学生投票定视觉皮肤;学期数据报告 |
| M4 全量 | 7-9 年级全单元、听力专项、作文批改、动画区(版权内容就位后)、正式美术资产(Lottie/Rive) |

## 9. 已定决策(2026-08-26,经确认)

1. **仓库转私有**:由仓库所有者在 GitHub Settings → Danger Zone 操作(工具无此权限)
2. **视觉定稿**:方向 A(新中式×二次元)为主皮肤 + 方向 C(徽章收集)为机制层;方向 B(电竞 HUD)保留在方案书中,试点班学生投票后可整体换肤
3. **产品工作名**:「萌宠英语岛」→「**书山英语**」,slogan「书山有路,AI 为径」;宠物升格为水墨神兽「墨墨」(金鹿角墨团,规避低幼感)
4. **客户原始需求全部保留**:积分任务/宠物粮盲盒(改「锦囊阁」,概率公示+10 抽保底)/宠物好友(默认关闭)/动画区时段门禁——形式升级,机制不变
5. **新增三个差异化玩法**(写入方案书):班级团战(匿名段位+集体荣誉,合规)/ 配音剧场(AIGC 自制短片,零版权依赖,复用评测引擎)/ 贴校内容运营(校历联动情景,双周更)
6. **原型 V3 已落地**:书山卷轴地图、神兽墨墨、吧唧墙(8 枚 R/SR/SSR/UR 成就徽章)、锦囊阁、中考模考入口(5 大题结构+朗读评分演示)
