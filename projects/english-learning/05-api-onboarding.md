## 二、讯飞开放平台(语音评测 ISE)⬅ 现在要做

### 关键差异:讯飞给的是三件套

DeepSeek 是一个 key,讯飞是 **APPID + APIKey + APISecret** 三个 32 位字符串,三个都要,缺一不可。

### 开通步骤

| # | 步骤 | 说明 |
|---|---|---|
| 1 | 注册账号 | [www.xfyun.cn](https://www.xfyun.cn) 右上角注册 |
| 2 | **实名认证** | 控制台 → 实名认证。**免费额度按认证等级发放,企业认证额度更高** |
| 3 | 创建应用 | 控制台 → 我的应用 → 创建新应用(应用名如「书山英语」,行业选教育) |
| 4 | 添加服务 | 在应用里找到**语音评测(流式版)**并开通 |
| 5 | 领免费额度 | 见下方「领哪几个」;**SDK 版与 WebAPI 版分开领、额度不互通**,我们用 WebAPI 版 |
| 6 | 复制三件套 | **见下方「凭证到底在哪」**,填入 `server/.env.local` |
| 7 | 关掉 IP 白名单 | 控制台服务页面默认可能开启 IP 白名单,开发阶段先关闭(或加本机外网 IP),否则握手直接失败 |

**创建应用后默认有每日 500 次调用额度**,足够开发调试;正式试点前再领/买正式服务量。

### 凭证到底在哪(最容易卡住的一步)

直达:**https://console.xfyun.cn/app/myapp**(或官网右上角「控制台」)

```
控制台 → 我的应用 → 点进某个应用 → 左侧点「语音评测」
        → 页面上方区块「服务接口认证信息」
           APPID / APISecret / APIKey  ← 三件套在这里
```

⚠️ 两个常见卡点:
1. **领免费套餐 ≠ 创建应用**,是两件事。只领套餐没建应用,凭证无处显示
2. 建了应用但**没在应用里添加「语音评测」服务** → 左侧没有该服务入口,自然看不到认证信息

补充:APPID 在「我的应用」列表页的应用卡片上就能直接看到;APIKey / APISecret 必须点进具体服务页才显示。

### 免费套餐领哪几个(个人/企业套餐页)

| 套餐 | 领? | 用途 |
|---|---|---|
| **语音评测** 1万次 | ✅ 必领 | 核心:跟读打分、中考模考五维评分 |
| **语音听写** 1万次 | ✅ 领 | 学生开口说话 → 转文字 → 喂给 DeepSeek,让 AI 对话变成「说」而非「打字」(演示杀手锏) |
| **在线语音合成** 1万次 | ✅ 领 | AI 回复朗读;同时验证讯飞是否有**英式(en-GB)音色**——没有的话示范音仍走 Azure |
| 语音转写 5小时 | ❌ | 长音频离线转写(会议记录场景),用不上 |
| 实时语音转写 5小时 | ❌ | 同上,用不上 |

三个一起领 = 完整语音闭环:**学生说 → 听写转文字 → DeepSeek 回答 → 合成朗读 → 评测打分**。

⚠️ **两个时间/额度陷阱**:
1. **免费额度有效期仅 3 个月**(转写类为 1 年)。MVP 6-8 周 + 试点 W9-10 刚好卡在窗口内,所以**现在领正合适,但不能再拖**。
2. **1 万次评测 ≈ 开发调试 + 小范围验证的量**:一个 65 人班每人每天练 10 次 = 650 次/天,**半个月就用完**;全量 1,365 人是 164 万次/年。
   → 免费额度**不能当成本基础**,试点班正式开跑前必须谈定正式服务量/包年价(见 [`03-quote-plan.md`](03-quote-plan.md) §2)。
3. 优先看**企业免费套餐** tab:额度通常显著大于个人套餐(需营业执照,见上方前置卡点)。

### ⚠️ 前置卡点:企业认证要营业执照

商用交付、对公付款、开发票都需要**企业实名认证**,而企业认证要提交营业执照。
→ 这正好是 [`docs/strategy/01-sales-playbook.md`](../../docs/strategy/01-sales-playbook.md) 里「第一堵墙:身份之困」那条:**公司主体没下来,这一步就卡住**。

**如果公司主体还在办**,两个过渡方案:
1. 先用个人认证账号跑 MVP 与试点(免费额度够用),主体下来后再迁到企业账号
2. 或由甲方以学校/其单位名义开企业账号,我们作为技术方使用(见下方账号归属)

### 账号归属:建议我们持有

| | 我们持有(推荐) | 甲方持有 |
|---|---|---|
| 成本 | 计入服务费,我们控成本、赚差价 | 甲方直付,我们赚不到这部分 |
| 灵活性 | 可随时切引擎(讯飞→驰声)不惊动客户 | 换供应商要客户配合 |
| 风险 | 用量超支我们承担 → 必须设告警与限流 | 甲方看得见每一笔调用 |

推荐我们持有,**合同里把 API 成本写进服务费**,对客户呈现为"包含在服务里"。同时在服务端做每日调用上限,防止意外超支。
