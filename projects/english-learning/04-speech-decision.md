# 04 · 语音技术选型决策

> 结论先行:**语音要拆成两件事**——「评测」(给学生打分)和「示范音」(标准发音)。
> 两者的引擎、成本模型、采购方式完全不同,混在一起谈会选错。

## 一、示范音(标准发音)——最重要的一个判断

### 必须是英式(en-GB),不是美式

江苏用的是**牛津译林版**,教材配套录音是**英式发音**。示范音跟教材对不上,学生跟读会困惑、英语老师第一节课就会挑出来。
→ 全站示范音统一 en-GB;AI 对话角色也用英音。这是"贴校"的细节,标准品不会为一个省份改。

⚠️ 教材具体册次的录音口音,建议签约后请校方英语教研组确认一次(一句话的事,但显得我们懂行)。

### 核心结论:批量预生成,不做实时 TTS

**教育内容是固定的**——单词表、课文、中考朗读 24 篇、情景对话固定句,全都是不变的文本。
所以正确做法是:**一次性批量生成 MP3 → 存对象存储/CDN → 永久复用**。

| | 实时 TTS(每次播放调用) | **预生成 + CDN(推荐)** |
|---|---|---|
| 成本 | 每次播放都花钱,随学生数线性增长 | **一次性几百元,之后为零** |
| 音质 | 受延迟限制,只能选快的 | 可以用最好的引擎(不赶时间) |
| 平板表现 | 依赖网络,弱网卡顿 | 可预下载,**弱网/离线可用** |
| 一致性 | 每次合成可能有微差 | 全校听到的是同一份音频 |

**只有 AI 自由对话需要实时 TTS**(文本是动态生成的),这部分单独选低延迟引擎。

### ⚠️ 现在原型用的浏览器 TTS 必须换掉

原型里的 `SpeechSynthesisUtterance` 是演示用的权宜之计。放到学生平板上:
- 安卓平板**经常没有 en-GB 音色**,会退化成美音、机械音,甚至完全不发声
- 各品牌平板表现天差地别,无法保证全校一致

→ **W1-2 机型适配清单必须测这一项**;正式版一律用预生成音频。

### 引擎推荐(示范音)

| 方案 | 引擎 | 适合 |
|---|---|---|
| **质量优先(推荐)** | Azure Neural HD `en-GB`(如 Sonia/Ryan) | 音质最好,约 $22/1M 字符。**生成在我们的构建流水线里跑一次,学生端只访问境内 CDN** —— 数据不出境、访问不绕路,合规与质量兼得 |
| 全境内单一供应商 | 讯飞在线 TTS / 火山引擎豆包 | 客户明确要求全链路境内、或想少一个供应商时选它。注意讯飞发音人授权:在线版新用户赠基础发音人,离线版发音人一次性授权 2000-4000 元/个 |
| AI 对话实时 TTS | 火山引擎豆包 TTS | 流式首包约 120ms(优于 Azure 约 150ms),英文 WER 3.5%,约 ¥0.003/千字符 |

> 以上价格为公开资料口径,采购前按控制台实价复核。

## 二、口语评测(打分)——建议讯飞 ISE 起步

| 引擎 | 结论 |
|---|---|
| **讯飞 ISE(推荐起步)** | ✅ 免费额度大(SDK/WebAPI 各 5 万次,够 MVP + 试点整学期);✅ 中高考同源技术是**销售资产**——"我们用的就是与听说考试同类的评测引擎",校长听得懂;✅ 接入文档完整(wss 流式) |
| 腾讯云 SOE | 题型最全(字/词/句/段落/**自由说**/关键词),音素级反馈。**AI 自由对话要打分时用它**(见下) |
| 驰声 Chivox | 考试级引擎,服务中高考听说 11 年。全量铺开后谈,商务报价 |
| 有道 / 百度 | 不作首选(有道无承考背书;百度无公开口语评测产品) |

### 一个容易踩的技术分叉

- **朗读/跟读/中考模考** → 有参考文本 → 讯飞 ISE 完全够用
- **AI 自由对话** → 没有参考文本,学生说什么不确定 → 需要「自由说」能力 → 腾讯 SOE,或 MVP 阶段先只做对话不打分(**推荐**:先跑通对话体验,二期再上自由说评分)

### 关于「用讯飞的引擎去打讯飞」

不矛盾,而且要主动讲清楚:**讯飞是我们的供应商,不是我们的对手。**
评测引擎是采购件——学校买的是整套贴校方案,不是买一个引擎。这话讲出来比藏着更显专业。

## 三、推荐组合(MVP 直接照此执行)

```
示范音(单词/课文/24 篇朗读/情景固定句)
  → Azure Neural HD en-GB 批量预生成 → 对象存储 + 境内 CDN
  → 一次性成本(见 §4),之后零成本、离线可用

口语评测(跟读/朗读/话题简述/模考)
  → 讯飞 ISE(免费额度起步,规模化后谈商务价或驰声)

AI 自由对话
  → 文本:DeepSeek v4-flash(已跑通)
  → 语音:MVP 先用预生成兜底/浏览器 TTS 演示;正式版火山引擎流式 TTS
  → 打分:二期接腾讯 SOE 自由说
```

**要买的 key,按优先级:**
1. **讯飞开放平台**(语音评测 ISE)—— 先注册领免费额度,MVP 就能跑
2. **Azure Speech**(或火山引擎,若要求全境内)—— 批量生成示范音,一次性
3. 火山引擎 TTS / 腾讯云 SOE —— 二期再说

## 四、成本影响(修正 03 的测算)

原测算把 TTS 当年度成本,现在修正:

| 项 | 原估 | 修正后 |
|---|---|---|
| 示范音 TTS | 计入年度 | **一次性 < ¥1,000**(见下方实测口径),年度 ≈ 0 |
| 语音评测 | ¥5,000–10,000/年 | 不变(78 万次/年,商务谈并发包) |
| CDN 流量(音频) | 未计 | 约 ¥500–1,500/年(音频体积小,可预下载) |

→ **年度硬成本不升反降**,示范音质量还更好。

字符量估算口径(用 `server/tts-batch.mjs --dry-run` 可按真实内容重算):
- 7-9 年级单词 + 音标例句 ≈ 2,000 词 × 约 50 字符 ≈ 10 万字符
- 课文/短文 + 中考 24 篇朗读 + 12 话题范例 ≈ 5 万字符
- 情景对话固定句 ≈ 2 万字符
- 合计约 **17 万字符** → Azure Neural HD 口径约 **$4**(≈ ¥30);即使全量重跑十次也不到 ¥500

## 五、给甲方怎么讲

> 「示范音我们统一用**英式发音**,和译林教材配套录音一致——不会出现学生跟读的和课本听的不是一个口音。
> 所有课文和单词音频是**提前生成好存在学校端的**,不占课堂网络、弱网也能播;
> 口语打分用的是**与各地听说考试同类的评测引擎**,分数标准不是我们自己定的。」

三句话,把「专业」「贴校」「可信」全讲到了。
