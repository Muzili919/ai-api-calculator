# 一人公司进阶:签单体系与主站改版

> 参考来源:一位程序员出身的一人公司创始人 8 年创业「五次碰壁」复盘。
> 核心结论:**甲方买的不只是能力,而是长期交付的确定感。**

本目录是把这套经验落到我们自己业务上的完整方案,共三份交付物:

| 文件 | 内容 | 用途 |
|---|---|---|
| [`01-sales-playbook.md`](01-sales-playbook.md) | 五堵墙对照 + 签单体系落地手册 | 内部执行清单 |
| [`02-website-blueprint.md`](02-website-blueprint.md) | 主站改版蓝图(定位/架构/文案/合规) | 改版开发依据 |
| [`../../prototype/homepage.html`](../../prototype/homepage.html) | 新主站首页高保真原型(自包含 HTML) | 直接浏览器打开预览 |

## 一句话结论

主站升级为「全栈工程师团队」的公司门面(不把自己框成教育公司),
以**教育数字化(平板 + MDM + 三大校本课程包)**为旗舰业务线,主要面向学校/渠道;
一人公司不靠「装大」建立信任,靠**可验证的透明**(公开数据、开源背书、创始人直接服务)给客户大公司级的确定感。
