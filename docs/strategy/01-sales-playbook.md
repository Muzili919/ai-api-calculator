# 01 · 一人公司签单体系落地手册

> 视频复盘的五堵墙:身份 → 效率 → 形象 → 规模 → 风险。
> 本手册把每堵墙对照到我们的现状(muzi.studio:全栈工程团队——定制开发服务 + ChineseLearn / EQ Trainer 两款产品 + 教育数字化项目「平板 + MDM + 校本课程包」),给出可执行清单。

## 0. 核心认知:确定感

视频作者的总结是「甲方购买的不仅是你的能力,更是长期交付的确定感」。对我们有两层含义:

- **接单业务(B 端甲方)**:担心的是「一个人做,烂尾了怎么办」。
- **教育业务(家长 / 学校 / 渠道)**:担心的更多——「会不会跑路」「内容安全吗」「孩子数据给谁了」「明年还更新吗」。
  教育客户为**持续性**付费,平板更是一次买断三年信任,确定感的权重比接单业务更高。

一人公司给不了「规模」,但可以给出**可验证的确定感**,这是整套体系的主线。

## 1. 第一堵墙:身份之困(主体与资质)

视频破局:注册公司,解决合同与发票。

我们的行动清单(教育 + 硬件业务的资质要求比纯软件外包多,按阶段推进):

### 基础主体(现在就要有)
- [ ] 公司主体,经营范围覆盖:软件开发、教育软件、智能硬件销售、技术服务
- [ ] 对公账户 + 开票资质(专票能力,B 端渠道谈判必问)
- [ ] 商标注册:核心品牌名,至少 **第 9 类**(电子产品/平板)、**第 41 类**(教育)、**第 42 类**(软件服务)
- [ ] 软件著作权:ChineseLearn、EQ Trainer、平板端系统各一件(成本低、谈单出示率极高)

### 线上业务合规
- [ ] 域名 ICP 备案(主站已运营,确认备案主体与公司一致)
- [ ] 若有在线付费/会员:确认是否需要经营性 ICP 许可证
- [ ] 教育移动应用(教育 App)备案:面向中小学生的学习类 App 属于重点监管对象
- [ ] 隐私政策 + 儿童个人信息保护规则(《儿童个人信息网络保护规定》对 14 岁以下有单独要求;《未成年人网络保护条例》2024 年起施行)

### 硬件上市前(平板量产前完成)
- [ ] 3C 认证(CCC,平板类强制)
- [ ] 质检报告、入网许可(如带蜂窝通信)
- [ ] 产品执行标准、说明书与保修卡合规文案

> ⚠️ 以上为方向性清单,具体以属地市场监管、网信、教育主管部门要求和专业律师/代办意见为准。

## 2. 第二堵墙:效率之困(谈单资料体系)

视频破局:标准化 PDF 案例集,把口头解释变成资料推进。

我们要建「**谈单资料包四件套**」,一次制作、反复使用、持续沉淀:

| # | 资料 | 用途 | 要点 |
|---|---|---|---|
| 1 | 公司/产品一页纸 | 初次触达,微信直接发 | 一屏讲清:我们是谁、做什么、凭什么、找谁 |
| 2 | 案例集 PDF | 推进到报价前发 | 结构见下 |
| 3 | 报价单模板 | 报价环节 | 分档报价 + 明确边界(含什么/不含什么)+ 付款节奏 |
| 4 | 谈单 PPT | 见面/视频会议 | 与官网同一套视觉,16 页以内 |
| 5 | 政策对照一页纸(教育线) | 给校长/教务,便于向局端转述 | 每门课程标注政策文件、课时落点、预算科目建议 |
| 6 | 校本方案书模板(教育线) | 预约演示后 48h 内发出 | 配置清单 + 课时安排 + 试点方案 + 分档报价 |

### 案例集 PDF 标准结构
1. 封面(品牌 VI)
2. 公司一页(定位 + 公开数据面板截图)
3. 案例 × N,每个案例固定四段:**客户背景 → 我们的方案 → 交付结果(数据)→ 界面截图**
4. 服务流程(见第 6 节)
5. 资质页(执照/软著/商标/备案,拍照即可)
6. 联系方式 + 二维码

### 沉淀机制(关键)
每结一个项目,**30 分钟内**按上面四段结构归档成案例页,进案例库。
经验只有变成资料,才能变成下一单的谈判筹码——这是视频作者第二堵墙的本质。

## 4. 第四堵墙:规模之困(确定感的正道)

视频破局:注册带「(集团)」字样的公司 + 注册商标,塑造实力形象。

**我们不建议照抄**,两个原因:

1. **合规风险**:《企业名称登记管理规定》(2021)对「集团」字样有条件要求(需具备集团母公司/控股结构),
   商标注册与企业名称登记是两回事,擦边玩法在教育行业尤其危险——家长与媒体对「虚假宣传」零容忍。
2. **不符合我们的品牌资产**:muzi.studio 现有的口碑恰恰来自「不藏失败,不美化数字」的透明人设,装大是自毁差异化。

### 替代打法:可验证的确定感

把「小」变成卖点,用**可以被第三方验证的事实**替代「规模暗示」:

| 大公司靠什么 | 我们靠什么 | 可验证方式 |
|---|---|---|
| 员工规模 | 创始人直接负责每一次交付 | 微信直连创始人,响应速度 |
| 品牌广告 | 公开运营数据面板 | 官网实时数据,不美化 |
| 资本背书 | 开源背书 | GitHub 18 个公开仓库、star 数 |
| 「大而不倒」 | 长期主义承诺 + 更新日志 | 每周公开进度,历史可查 |
| 销售团队 | 案例与作品自己说话 | 可试用的线上产品 |

> 一人公司的信任公式:**确定感 = 透明度 × 持续时间**。装出来的规模经不起尽调,公开的记录越久越值钱。

### 校园渠道的确定感(教育线专属)

学校决策链(校长/分管副校长/教务/信息中心)看的和企业甲方不同:

- **出了问题找得到人**:本地化服务承诺、响应时效写进合同
- **说得清**:每门课的政策依据与课时落点一页纸讲明白(资料包第 5 件)
- **试点先行**:1–2 个班先跑一学期,用学期数据汇报换续期扩面——试点校案例是校园渠道最强背书
- **数据合规**:未成年人数据协议、数据归属写清楚,这在学校侧是加分项不是负担

## 5. 第五堵墙:风险之困(抗风险与合规)

视频教训:客户业务涉灰,公司账户被冻结,业务停摆。

一人公司抗风险能力天然弱,提前布防:

### 客户与收款
- [ ] 接单前尽调:企业信息核验(天眼查/企查查)、业务合法性判断,**灰产一律不接**(支付、博彩、仿冒、刷量等)
- [ ] 收款全部走对公账户,合同、发票、流水三对应
- [ ] 付款节奏写进合同:预付 30–50%,里程碑分段,尾款不超过 20%

### 合同必备条款
- [ ] 验收标准(可量化,防止无限改稿)
- [ ] 知识产权归属与源码交付边界
- [ ] 延期责任与不可抗力
- [ ] 需求变更 = 增补报价的机制

### 业务连续性(关键人风险)
- [ ] 代码、数据、文档异地备份(一人公司,创始人生病 = 公司停摆,文档化是唯一解药)
- [ ] 交付流程 SOP 化,极端情况下可由外包临时接手
- [ ] 核心账号(域名、服务器、公众号、商标)权属全部在公司名下,整理成资产清单

### 教育业务特有
- [ ] 内容审核机制(题库、AI 生成内容都要过审)
- [ ] 未成年人数据合规(最小化收集、家长同意、不做算法推荐沉迷设计)
- [ ] 广告与宣传合规(见 02 文档「文案合规」一节):
  - 《广告法》第 9 条:禁用「最」「第一」「顶级」「领导者」等绝对化用语
  - 教育类广告不得对升学、提分、通过考试作出明示或暗示的保证性承诺

## 6. 统一服务流程(对外展示版)

四步流程,官网、PPT、案例集统一使用:

1. **沟通需求** — 30 分钟免费咨询,明确目标与预算
2. **方案与报价** — 48 小时内给出书面方案 + 分档报价
3. **试用体验** — 产品可先试用;定制项目先交付可验证的最小版本
4. **签约交付与陪跑** — 里程碑推进,交付后持续迭代与响应
