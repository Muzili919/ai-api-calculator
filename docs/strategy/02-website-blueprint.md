## 2. 教育业务线:产品与卖点结构

学校买的是「管得住、用得好、说得清」的整体方案,三层结构(对应原型「三层 stack」):

1. **设备与管控层**:教育平板 + MDM(批量部署、应用白名单、时长策略、远程运维)
2. **数据与平台层**:学情/测评数据沉淀为校本数据资产(学生成长档案、班级学情、过程性评价)
3. **课程与内容层**:三大课程包,每门都有政策抓手

### 课程包明细

| 课程包 | 内容模块 | 课时落点 | 政策抓手 |
|---|---|---|---|
| ① AI 素养课 | AI 原理启蒙 / 工具实操 / 用 AI 学习;分学段课件 | 信息科技课 / 校本课程 | 中小学人工智能教育普及要求(2030 前基本普及) |
| ② 生涯规划与选科指导 | 兴趣能力测评 + 个体报告 / 选科模拟(组合→专业→院校) / 专业库 / 生涯课堂 | 校本课程 / 班会课 | 新高考「3+1+2」省份生涯教育要求;江苏高一选科刚需,学校普遍缺专业师资 |
| ③ 数字素养包 | 网络安全 / 反诈情景课 / 个人信息保护 | 法治教育课时 / 班会课 | 反诈进校园(公安+教育联合专项)、《未成年人网络保护条例》学校网络素养教育义务、每年 9 月网络安全宣传周「校园日」 |

组合逻辑(写进方案书,官网点到为止):

- ①+③ 可打包为「数字素养课程群」:一个内容族,两个政策抓手,整体采购
- ③ 与 MDM 是天然故事闭环:学校买管控是为了「管住平板」,配一门「正确用网络」的课,卖相一体
- ② 的测评与选科数据沉淀在平台,**续期即延续**——绑定效应是内部逻辑,对外表达为「校本数据资产」

### 数据与运维注意(工程侧)

- 选科模拟的数据底座(专业选科要求、院校专业组)**每年更新**,以教育部选考科目要求指引及江苏省考试院当年文件为数据源,做成年度更新管线,并在报告页标注数据版本与截止日期
- 测评报告措辞避免「决定论」:给建议区间,不给「你只能选 XX」的结论(家长投诉风险)
- 未成年人测评数据:最小化收集、校方协议明确数据归属与用途、不用于商业画像

## 3. ⚠️ 内外话术分离表(重要)

谈单/内部策略语言不能上官网——学校、家长、主管部门都会看官网:

| 内部说法(方案书/谈单可用) | 官网表达 |
|---|---|
| 有「名分」(校本课程/班会) | 「课程对应明确的课时安排」 |
| 预算理由是「新高考配套」 | 「新高考省份生涯教育配套方案」 |
| 数据沉淀「加深绑定」「越用越离不开」 | 「学情数据沉淀为校本数据资产,成果可延续」 |
| 「管学生」 | 「课堂纪律与家校规则由学校说了算」 |
| 「政策抓手」「硬任务」 | 「政策落点」「以当年主管部门文件为准」 |

同样保留 V1 的广告法红线:「中国教育的先驱 / 领导者 / 第一」不用(绝对化用语),
提分/升学承诺不写;抱负用愿景句式放「关于我们」。
